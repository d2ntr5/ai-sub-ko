처음 한 번만 받으면 인터넷 없이도 번역해요. 미리 받아 두면 AI 번역이 막힐 때 바로 이어서 번역해요. 크롬 138 이상에서 쓸 수 있어요.

응답 지연·혼잡·네트워크는 1분 뒤 원래 엔진으로 돌아가고, 키·크레딧 문제는 고칠 때까지, Claude 하루 상한은 자정, Gemini 하루 한도는 태평양 시간 자정(한국 오후 4~5시)까지 기다려요.

음성 번역 자막이 없는 영상의 소리를 맥 안에서 받아 적어 번역 · 1.0

크롬 내장 음성 인식(맥 안)으로 탭 소리를 받아 적어 원문으로 써요. 소리를 서버로 보내지 않아요. 번역은 위 엔진(Claude → 크롬 내장)이 해요. 시작 · 멈추기는 팝업의 「음성 번역 시작」이나 ⌥L — 크롬은 사용자가 누른 뒤에만 탭 소리를 넘겨줘요 (단축키 바꾸기: chrome://extensions/shortcuts).

적용 사이트

다른 사이트는 팝업의 이 사이트에서 켜기로 그 자리에서 추가해도 돼요. 자막을 자동으로 못 찾으면 팝업의 자막 직접 고르기로 영상 위 자막 글자를 클릭해 주세요. 사이트별로 기억해요. 자막이 영상 그림에 박혀 있거나 없는 영상은 번역할 수 없어요.

사이트별 설정 · F1 TV

라이브 영어 자막을 읽어 번역해요. F1 용어집을 항상 써요. 다시보기처럼 자막 전체가 브라우저에 들어오는 영상은 일반 영상처럼 미리 번역해요.

사이트별 설정 · YouTube

영어 자막(CC)을 켜면 플레이어가 받아 온 자막 전체를 그대로 써서 미리 번역해요 (자막을 다시 요청하지 않아요). 되감기·건너뛰기를 해도 재생 시각에 맞는 줄을 바로 보여 드려요.

사용법
내보내기
  1. 범위를 고르세요 (지금 묶음 / 모든 묶음 / 내가 고친 것만)
  2. 형식을 고르세요. 다른 Mac·백업은 JSON, 엑셀이나 Numbers 로 고치려면 CSV
  3. 내보내기 → 다운로드 폴더에 ai-sub-ko-용어집-클라우드-20261026.json 으로 저장돼요
가져오기
  1. 가져오기… → JSON 또는 CSV 파일을 고르세요
  2. 미리보기에서 새 용어·바뀌는 용어·같은 용어 수를 확인하세요
  3. 합치기(지금 목록에 더함, 같은 영어는 파일 쪽으로) 또는 통째로 바꾸기(파일에 든 묶음만)를 고르세요
  4. 적용 → 바로 번역에 쓰여요. 바로 전 상태는 되돌리기 한 번으로 되돌릴 수 있어요

· 없는 묶음 이름을 쓰면 그 이름으로 새 묶음이 생겨요. 영어 칸이 비었거나 처리 값이 틀린 줄은 미리보기에서 빨갛게 보이고 건너뛰어요
· API 키·사용량은 파일에 들어가지 않아요. 용어집만 나가요
