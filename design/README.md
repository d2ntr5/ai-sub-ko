# 화면 결정 기록

## AI 번역 표시 (1.0.28, 2026-11-17) — 인공지능기본법 제31조 대비
시안은 비공개라 링크를 두지 않는다. 결정만 적는다.

| 항목 | 결정 |
|---|---|
| 자막 단추 글자 | `AI 번역·Claude` · `AI 번역·Gemini` · `AI 번역·크롬` (전에는 `KO·Claude` · `KO·Lite` · `KO·크롬`) |
| 툴팁 | 「AI 번역 · 엔진: …」 |
| 자막 상자 안 「AI」 표시 (안 B) | **채택 안 함** — 법 제31조 ② 는 표시 위치를 정하지 않음. 단추가 자막과 함께 늘 보임 |
| 크롬 내장 번역 | 공식 문서는 번역 전용 모델(expert model)이라 하지만 보수적으로 같은 「AI 번역」 표시 |
| 사전 고지 (제31조 ①) | 팝업 번역 엔진 아래, 상세 설정 Claude 키 칸 위, 스토어 설명 첫 줄, README · PRIVACY |
| 단추가 보이는 조건 | 번역이 켜져 있거나 음성 번역 중이면 늘 보임 (꺼지면 자막도 없음). 영상 전체 화면에서도 맨 위 층 |
