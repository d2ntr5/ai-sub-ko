# AI 자막 번역 (ai-sub-ko)

맥 크롬에서 **F1 TV · YouTube · 강의 사이트**(AWS Skill Builder, Anthropic Academy, 직접 추가한 사이트) 영상의 영어 자막을 읽어,
**Claude · Gemini 3.5 Flash Lite · 크롬 내장 번역** 으로 한국어 자막을 영상 위에 보여 주는 크롬 확장. **macOS 전용.**
**1.0 부터 음성 번역**: 영어 자막이 없는 영상은 탭 소리를 크롬 내장 음성 인식으로 **맥 안에서** 받아 적어(영어 · 일본어) 번역한다. 소리를 서버로 보내지 않는다.

- 크롬 웹 스토어: 게시 준비 중 (주소가 정해지면 여기에 적습니다)
- 0.x 버전은 이 저장소에 없습니다. 1.0 부터 이 공개 저장소에서 이어 갑니다.

## 설치

**크롬 웹 스토어**(게시되면): 스토어 페이지에서 **Chrome에 추가** — 업데이트도 크롬이 알아서 받습니다.

### 직접 설치 (개발자 모드)

1. 이 저장소의 **Releases** 에서 `ai-sub-ko-<버전>.zip` 받기 (예: `ai-sub-ko-1.0.0.zip`)
2. 압축을 풀면 버전이 없는 **`ai-sub-ko` 폴더**가 나온다. **지우지 않을 곳**에 둔다 (예: `~/Applications/ai-sub-ko`) — 크롬이 이 폴더를 계속 읽는다
3. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** → 2 의 폴더 선택
5. 자동으로 열리는 **상세 설정**에서 Claude API 키(라이브용)·Gemini API 키(일반 영상 미리 번역용)를 넣고 각각 **연결 테스트** → **저장**, **크롬 내장 번역 › 번역 모델 내려받기**. 키가 없어도 크롬 내장 번역으로는 쓸 수 있다
6. 툴바의 퍼즐 아이콘에서 고정(핀)해 두면 팝업을 바로 열 수 있다

### 업데이트

1. 새 `ai-sub-ko-<버전>.zip` 을 풀어 나온 `ai-sub-ko` 폴더를 쓰던 자리에 그대로 덮어쓴다 (Finder 에서 ‘대치’)
2. `chrome://extensions` 에서 ↻ → 영상 탭 새로고침(⌘R)

- 같은 자리에 덮어써야 API 키·용어집·설정이 그대로 남는다 (개발자 모드 확장은 폴더 위치로 구분). 다른 자리에 풀면 다른 확장으로 잡혀 키를 다시 넣어야 하니, 그 전에 상세 설정 › 용어집 **내보내기**로 받아 둔다
- 0.4 이하에서 올리면 크롬이 새 권한(스크립트 등록·Gemini API·YouTube·강의 사이트)을 한 번 물어본다
- 옛 이름(f1-ai-sub-ko) 폴더를 쓰고 있었다면 그 폴더에 덮어써도 된다 (폴더 이름은 상관없고 위치만 같으면 됨)

## 쓰는 법

1. 영상 재생 → 플레이어 자막(CC)을 **English** 로 (YouTube 는 ‘영어 (자동 생성)’ 도 됨)
2. **⌥ Option + K** 또는 툴바 팝업의 **켜기** (켜면 화면 오른쪽 위 — YouTube 는 상단 바 **+ 만들기** 왼쪽 — 에 **KO** 버튼이 보이고, 누르면 꺼지며 버튼이 사라진다)
3. 버튼에 지금 엔진이 보인다: **KO·Claude**(Claude 주황) · **KO·Lite**(Gemini 파랑→보라) · **KO·크롬**(크롬 파랑) — 엔진 BI 색, 팝업·상세 설정 버튼도 같은 색
4. **⌥ Option + O**: 영어 원문 보이기 ↔ 숨기기
5. 목록에 없는 사이트는 팝업 › **이 사이트에서 켜기**, 자막을 못 찾으면 팝업 › **자막 직접 고르기** (영상 위 자막 글자 클릭 → 사이트별로 기억)
6. **자막이 없는 영상 (1.0 음성 번역)**: 팝업 › 음성 번역 › 원문 언어(영어 · 일본어) → **음성 번역 시작**, 또는 **⌥ Option + L** (다시 누르면 멈춤)
   - 처음엔 언어 팩을 한 번 받는다 (팝업 · 상세 설정의 **언어 팩 받기** — 크롬은 사용자가 누를 때만 받게 해 준다, 이 확장용으로 따로).
   - 쓸 수 없는 크롬이면 단추가 회색이고 그 아래에 이유 · 해결이 늘 보인다 (크롬 업데이트 · 언어 팩 받기 · 크롬 자체 페이지 · 다른 곳에서 탭 소리를 쓰는 중). ⌥L 도 같은 안내를 영상 위에.
   - 영상 위 **음성 번역** 초록 표시 · 크롬 탭의 「공유 중」 표시. 소리는 그대로 들린다. 받아 적는 중인 원문 끝은 흐리게.
   - 번역은 라이브처럼 Claude → 크롬 내장 (Flash Lite 미리 번역은 자막 전체가 있을 때만). 일본어 원문을 크롬 내장 번역으로 하려면 일본어 → 한국어 모델도 받는다.

### 번역 엔진

| 엔진 | 품질 | 속도 | 비용 | 먼저 쓰는 곳 |
|---|---|---|---|---|
| Claude Haiku 5.5 | 상 · 문맥·용어집 | 약 0.5~1.5초 | 2시간 약 $0.1 (API 키) | 라이브 |
| Gemini 3.5 Flash Lite | 상 · 앞뒤 문맥을 다 봄 | 미리 번역 → 재생 중 0초 | 무료 등급 하루 500회 · 분당 15회 | 일반 영상 |
| 크롬 내장 번역 | 중 · 줄 단위 직역 + 용어집 보정 | 0.1~0.3초 · Mac 안 | 무료 · 키 없음 | 키가 없을 때 · AI 가 안 될 때 |

- **엔진은 자동**: 일반 영상(자막 전체를 받음) = Flash Lite → Claude → 크롬 내장, 라이브(F1 TV·YouTube 라이브·자막 전체를 못 받는 영상) = Claude → 크롬 내장. **키가 없는 엔진은 건너뛴다**
- 팝업에서 고른 엔진은 **그 탭에만** (자동으로 되돌리기 가능). 키가 없는 엔진은 흐리게 ‘키 없음’ 으로 보이고 고를 수 없다. 라이브 탭(F1 TV 등)에서는 Flash Lite 도 ‘일반 영상만’ 으로 고를 수 없다 (YouTube 는 자막(CC)을 켜면 일반 영상으로 잡힘)
- **AI 번역이 안 될 때 크롬 내장 번역** 스위치(팝업·상세 설정): 끄면 자막을 멈추고 이유만 알려 준다
- **크롬 번역 모델**은 팝업·상세 설정의 **내려받기** 버튼으로 받는다 (크롬이 사용자가 누를 때만 허락). 안 받았으면 크롬 내장 번역은 쉬고 안내만 띄운다
- **미리 번역**: YouTube 는 영어 자막(CC)을 켜면 플레이어가 받아 온 자막 전체를 그대로 넘겨받아(다시 요청하지 않음) 100줄씩 Flash Lite 에 보낸다. 지금 재생 위치부터 먼저, 끝난 줄부터 Gemini 번역으로 바뀌고 그동안은 크롬 내장 번역. 같은 영상은 저장해 두고(최근 30편) 다시 요청하지 않는다. 다른 사이트는 브라우저 자막 트랙에 줄이 다 들어와 있으면 같은 방식
- 사람이 만든 한국어 자막이 있는 YouTube 영상은 그걸 켜 주고 번역하지 않는다 (끌 수 있음)
- YouTube 광고 중에는 번역하지 않는다 (광고 자막에 비용을 쓰지 않음)

### 이럴 때
- **버튼이 다른 엔진으로 바뀜**: 응답 지연·혼잡·네트워크 → 1분 동안 대신 번역 후 저절로 / 키·크레딧·모델 문제 → 고칠 때까지 / Claude 하루 상한 → 자정까지 / Gemini 하루 한도 → 태평양 시간 자정(한국 오후 4~5시)까지 (Claude 키가 있으면 Claude 로)
- **‘영어 자막이 안 보여요’**: CC 에서 영어를 켠다. 그래도 그러면 팝업 › **자막 직접 고르기**, 또는 **진단 복사** 결과를 보내 준다
- **‘이 영상에는 영어 자막이 없어요’**: YouTube 에 영어 자막 트랙이 없음 — 번역할 원문이 없다
- **‘확장이 업데이트됐어요’**: 영상 탭을 새로고침(⌘R)

### 툴바 팝업
- 켜기, **적용 사이트**(켜기/끄기, **＋ 이 사이트에서 켜기**)
- 상태: 영어 자막 감지(어디서 읽는지·미리 번역 몇 줄), 엔진(평균 응답·실패·대신 번역 이유), 쓰는 용어집 묶음
- **번역 엔진** 3개 (이 탭에만, 키 없는 엔진은 고를 수 없음), AI 안 될 때 크롬 내장 번역 스위치, 크롬 번역 모델 내려받기(안 받았을 때), 지난 자막·원문 보이기, 사이트 영어 자막 숨기기, 맨 아래에서 띄우기(0~40%), 글자 크기(70~160%)
- 오늘 사용량: Claude 예상 금액/상한 막대, Flash Lite 횟수/500 막대, 크롬 내장 횟수 (키가 없으면 ‘키 없음’)
- **자막 직접 고르기**, **진단 복사**, 버전 · macOS 전용

### 상세 설정
- 엔진 이름·섹션 제목 앞에 각 엔진 로고, 저장·내려받기 버튼은 파란색 하나로 통일 (확장 아이콘도 파란색)

- **Claude API**: 키, 모델, **연결 테스트 · 모델 새로고침** (마지막 테스트 결과·시각은 저장하거나 다시 열어도 남고, 엔진 카드에도 보임. ‘저장됨’ 은 버튼 옆에 따로) (이 키로 쓸 수 있는 최신 Haiku·Sonnet 을 받아 목록을 바꾸고, 고른 모델이 빠졌으면 같은 계열 최신으로)
- **Gemini API**: AI Studio 키(형식은 따지지 않음), **연결 테스트** (마지막 결과 남음) — 모델 목록에서 Flash Lite 최신 이름을 찾고 번역해 응답 시간·결과, 오늘 남은 요청을 보여 준다
- **적용 사이트**: 표(켜기/끄기 · 자막 위치(기본 제공·자동 찾기·직접 고름) · 용어집), 주소로 사이트 추가, 직접 고른 위치 지우기 / YouTube: 자동 생성 자막도 번역, 한국어 자막 우선, 용어집 고르기
- **비용 상한** (Claude 만), **사용량** (엔진별 오늘 · 이번 달 Claude · **영상 종류별로 엔진이 하는 일** 표: 전체 자막 영상 / 실시간 자막 영상 / 토큰)
- **용어집**: 묶음 6개(아래) · 묶음 안 구분 거르기 · 줄마다 영어/구분/처리/한국어 바로 고치기 · 추가 · 영화·드라마 설정
- **내보내기 · 가져오기** (사용법이 같은 칸에 있음): 범위(지금 묶음 / 모든 묶음 / 내가 고친 것만) · 형식(JSON / CSV) → 다운로드 폴더에 `ai-sub-ko-용어집-클라우드-20261026.json`. 가져오기는 미리보기(새 · 바뀜 · 같음 · 건너뜀과 이유) → 합치기 / 통째로 바꾸기(파일에 든 묶음만) → 적용 → 되돌리기 한 번 가능
- **정보**: 버전, 지원 환경(macOS 전용 · 크롬 138 이상)

```
  │     └─ 번역: Claude('f1ko-translate'), 직전 원문 4줄 문맥 → 실패 → 크롬 내장 (모델을 받았을 때, 스위치가 켜져 있을 때)
  ├─ 원문이 사라지면 0.3초 뒤 한국어 자막도 지움, 되감기·건너뛰기하면 바로 지움
  └─ 자막 상자: 영상 기준 (맨 아래 + 영상 높이 × 띄우기 %, 글자 크기 = 영상 폭 비례 × 글자 크기 %)

background.js (service worker, module) — API 키는 여기만
  ├─ Claude: POST api.anthropic.com/v1/messages (thinking adaptive + effort low + 답 형식 JSON {ko}, system = 규칙 + 묶음 규칙 + 용어집, cache_control)
  │          연결 테스트 때 GET /v1/models 로 계열별 최신
  ├─ Flash Lite: POST generativelanguage…/models/{모델}:generateContent (JSON 스키마 {lines, names}), 분당 15회 간격, 하루 500회 센다
  ├─ 사용량: Claude·크롬 = 현지 날짜, Gemini = 태평양 시간 날짜 (storage.local)
  └─ 이 사이트에서 켜기: chrome.scripting.registerContentScripts + 지금 탭에 바로 주입
```

- 빌드 없는 확장이라 SDK 없이 `fetch` 로 직접 부른다
- 저장: `storage.sync` = 엔진·모델·보기·상한·사이트 / `storage.local` = API 키·용어집·사용량·켜짐·자막 위치·미리 번역 (키는 기기 밖으로 안 나감)
- 영어 자막 숨기기는 화면에서만(투명): 자막 요소는 `opacity: 0`, 자막 트랙은 `mode = 'hidden'` (cue 는 계속 들어옴). 끄면 되돌림

### 비용
- Claude (Haiku 5.5, 100만 토큰당 입력 $0.10 / 출력 $0.50): 자막 한 번 ≈ 지시문 캐시 읽기 약 1,000 + 입력 약 150 + 출력 약 50 토큰 ≈ $0.00005. 2시간 레이스(약 2,400번)에 **대략 $0.1**
- Gemini 무료 등급: 0원. 20분 영상 ≈ 자막 400줄 = 요청 4~5번 → 하루 500회면 영상 100편 정도. **무료 등급은 보낸 자막이 Google 제품 개선에 쓰일 수 있다**
- 예상 금액·남은 요청은 이 기기에서 센 대략값. 실제는 Console(platform.claude.com) Billing, AI Studio › 비율 제한

## 아직 확인 못 한 것

- **음성 번역 실제 방송 소리** (1.0): 크롬 157 에서 macOS 음성(say)으로 만든 영어 · 일본어 샘플로만 시험 — 첫 글자 0.5~0.9초, 틀린 비율 영어 강의 2% · 소음 섞인 F1 해설 11~15% · 일본어 강의 2.6% · 소음 섞인 일본어 F1 8.3%, 메모리 약 250 MB. 실제 F1 TV 리플레이 · 자막 없는 YouTube · 강의, 한 시간 넘게 켜 두기(끊김 · 다시 시작)는 아직
- 음성 번역 최소 크롬 버전: 판정은 기능이 있는지로 하고, 안내 문구의 「139 이상」은 크롬 문서로 다시 확인할 것
- ⌥L 단축키(chrome.commands)를 실제 키로 누른 시험 — 자동 시험은 팝업 단추로만 함

- Flash Lite 응답이 한 줄에 8초, 15초 넘게 걸린 적이 있다 (실사용 연결 테스트). 0.6.1 에서 생각 수준을 minimal 로 지정하고(거부하면 빼고 다시) 연결 테스트 대기 45초·미리 번역 대기 90초로 늘렸다. 무료 등급 서버 지연이면 이걸로는 안 줄어든다
- 크롬 번역 모델 내려받기 진행률 (클라우드 세션에서는 모델 서버에 닿지 않아 확인 못 함)
- **F1 TV 자막이 실제로 어디에 그려지는지** — 첫 실사용 때 팝업의 감지 상태·진단 복사로 맞춘다
- YouTube 실제 페이지: 플레이어가 timedtext 를 지금도 json3 로 받는지, 한국어 자막 켜기(`setOption('captions','track')`)가 되는지
- AWS Skill Builder·Anthropic Academy 플레이어의 자막 위치 (자동으로 못 찾으면 직접 고르기), 영상이 다른 도메인 iframe 안에 있는지
- 실제 API 응답 지연·캐시 적중 (설정 › 연결 테스트)
- 0.6.4 화면을 실제 Mac 크롬에서: 존댓말로 길어진 영상 위 안내가 넘치지 않는지, 엔진 로고·파란 아이콘이 툴바·팝업에서 또렷한지

클라우드 세션에서 확인한 것: Playwright 의 Chromium 에 확장을 불러와 상세 설정·팝업이 오류 없이 뜨는지(라이트·다크 모드), 가짜 YouTube 페이지(가짜 Gemini 응답)에서 자막 전체 미리 번역 → 재생 시각에 맞춰 줄이 바뀌고 끝나면 지워지는지, 가짜 강의 페이지에서 자막 직접 고르기 → 기억 → Claude 번역 → 크레딧 오류 때 크롬 번역으로 넘어가는지, 용어집 CSV 가져오기(미리보기·적용·되돌리기)·내보내기.

## 개발

```
ai-sub-ko/
├── manifest.json        MV3, 최소 크롬 138, 권한 storage·scripting + Anthropic·Gemini API·적용 사이트, 나머지 사이트는 선택 권한
├── background.js        Claude·Gemini Flash Lite 호출, 사용량·상한·하루 한도, 사이트 등록 (module)
├── content.js           자막 읽기·끊기·번역·미리 번역·자막 직접 고르기·화면 (lib 는 동적 import)
├── yt-main.js           YouTube MAIN world: timedtext 응답·트랙 목록 넘기기, 한국어 자막 켜기
├── overlay.css          KO 버튼(엔진별 색)·안내·자막 상자·고르기 막대, 영어 자막 숨기기
├── popup.html/js/css    툴바 팝업
├── options.html/js      상세 설정
├── lib/                 settings · sites · glossary · glossary-io · prompt · gemini · vod · errors · cost · segment · translator (ES 모듈)
├── tests/               node --test (lib + 가짜 chrome·fetch 로 background)
├── icons/               확장 아이콘(파란색, scripts/make_icons.py 로 그림) · 엔진 로고 claude/gemini/chrome.svg
└── scripts/package.sh   build/ai-sub-ko-<버전>.zip · build-<버전>.json
```

- 테스트: `cd ai-sub-ko && node --test`
- 빌드·배포: GitHub Actions(`.github/workflows/ai-sub-ko.yml`) — 문법·manifest 확인 → 테스트(작업 브랜치만, main 은 건너뜀) → zip → (main 만) 릴리스 `ai-sub-ko-latest` 에 `ai-sub-ko-<버전>.zip` · `build-<버전>.json`
- 디버그: `content.js` 의 `DEBUG = true` → 영상 탭 개발자 도구 콘솔의 `[AISUBKO]`. background 로그는 `chrome://extensions` 확장 카드의 ‘서비스 워커’
